# Method Schedule 0.1.0

The first release: a free, open scheduling app for film and TV that keeps your schedule in a plain file you own. It is an early alpha, for trying things out on invented productions before you trust it with a real shoot.

## From script to stripboard

![The stripboard of Field Station, an invented production: four shoot days of scenes, banners and day breaks](../../assets/screens/board-light.png)

- **Import a script.** Fountain (.fountain) and .fdx scripts come in as one breakdown sheet per scene, with their page lengths, and later drafts merge into the schedule you already have.
- **Break it down.** Cast, props, wardrobe, vehicles and every other category on each sheet, with quick add and elements you can link, merge and renumber.
- **Schedule on a stripboard.** Drag strips into days, add banners and day breaks, break the board automatically by pages or time, and keep several boards and sub-boards for different plans.
- **Three looks.** Paper, the default, follows your computer's light or dark setting; Graphite is always dark; Ledger is a full-color board like a printed one. Choose in Settings.

## Counts you can check

![The day out of days for Field Station: each cast member's work days across the shoot](../../assets/screens/dood-light.png)

- **Day out of days.** Start, work, hold, travel and finish for every element, with holds, drops and holidays following the rules schedulers use.
- **Explain this count.** Ask why any number is what it is, and see the reasoning date by date.
- **Calendar, conflicts and red flags.** Days off, events and holidays on a calendar; elements booked twice and dates an actor can't work are marked on the strips.

## Paper and files

- **Print and save as PDF.** The board, one-line and shooting schedules, the day out of days, element lists, the calendar and a call sheet for any shoot day.
- **Spreadsheets.** .xlsx and .csv files for the reports that are tables.
- **Hand the shoot days to Method Budget.** Export for Budget writes the shoot days and each element's work days for the budget to read.
- **Your file, safe.** Autosave, recovery after a crash, backups you can revert to, and a question when someone else changes the file while it's open, with a merge.

## For the command line and coding agents

![The method-schedule command listing Field Station's shoot days](../../assets/screens/cli-light.png)

- **The same schedule from a terminal.** Check, report, export and merge from the command line, and a git merge driver for schedules kept in git.
- **Coding agents.** An MCP server lets an assistant read and edit schedules on your computer, only in the folders you name.

## Known gaps

- Windows and Linux builds are made automatically but nobody has installed them yet. The Windows installer is unsigned, so Windows shows a warning before it runs.
- Printing uses Letter paper only.
- Updates: this release checks for newer versions, but there is nothing newer to find yet.
