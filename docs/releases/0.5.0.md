# Method Schedule 0.5.0

Method Schedule now imports scripts straight from Method Storyteller with their exact pages, merges against any copy of a schedule, and prints the drift since a schedule lock.

## Scripts from Method Storyteller

- **Exact pages, nothing estimated.** File > Import Script reads a script scenes file (`.mscenes`) that Method Storyteller exports. Every scene arrives with the script's own page and length in eighths, so the board adds up to the script.
- **More of the script comes with it.** Lettered scene numbers and locked pages, story days, the characters who are in a scene without speaking, the episode and act, the scene's title and summary as its synopsis, and the scenes the script has omitted, struck on the board and counting no pages.
- **Revisions too.** Import Script Revision reads the same file, so a new draft from Method Storyteller updates the schedule you already have.

## Working together

- **Merge against any copy.** When you merge changes from another copy, the version both copies started from can now be any schedule file you pick, not only a backup or the file on disk.
- **Print the drift.** Schedule Locks prints the drift since a lock, actor by actor, beside the spreadsheet and CSV exports.

## Smaller changes

- **Plainer names for files.** Exports, imports and their settings now name file types, such as spreadsheet (.xlsx), .fdx and .mscenes, rather than other programs.

## Known gaps

- On an Intel Mac, the app has been tested by the automated tests, run the way an Intel Mac runs them, but not yet by a person on one.
- Windows and Linux builds are made and tested automatically, but nobody has installed them by hand yet. The Windows installer is unsigned, so Windows shows a warning before it runs.
- On Windows and Linux, opening a second file while the app is running starts a second copy of the app.
- Printing uses Letter paper only.
