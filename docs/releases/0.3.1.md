# Method Schedule 0.3.1

A security fix for the connection the app uses to check for updates. Nothing else changes.

## Security

- **Update checks trust only certificates they should.** Two problems found this week in the code that checks the update server's certificate are fixed: it could accept certificates from authorities that browsers no longer trust. Updates were already safe to install, since the app checks each download's signature before installing it.

## Known gaps

- On an Intel Mac, the app has been tested by the automated tests, run the way an Intel Mac runs them, but not yet by a person on one.
- Windows and Linux builds are made automatically, but nobody has installed them yet. The Windows installer is unsigned, so Windows shows a warning before it runs.
- Printing uses Letter paper only.
- What was shot isn't shown on the board or in the reports yet.
